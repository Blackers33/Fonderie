# Internationalisation (i18n)

Anglais et français, extensible ; périmètre actuel : `apps/mobile` uniquement.

- **Textes** : tout texte affiché à l'utilisateur passe par `t('…')`, avec sa clé en FR et EN dans `apps/mobile/lib/i18n/locales/{en,fr}.json`. Un seul namespace ; les clés sont regroupées par écran ou fonctionnalité (`routineCard.*`, `restTimer.*`…), et `common.*` pour ce qui est partagé.
- **Init** : synchrone dans `apps/mobile/lib/i18n/index.ts`, branchée par un import à effet de bord dans `apps/mobile/app/_layout.tsx`, sans Provider ni écran de chargement. La langue vient de l'appareil (`expo-localization`).
- **Noms d'exercices** : traduits en base (`exercise_translations`), pas dans les JSON (voir `docs/agents/data-model.md`).
- **Choix manuel de la langue** : pas encore implémenté. À câbler avec l'écran Settings ; ce choix primera alors sur la détection automatique.
